\# CashPilot AI



CashPilot AI is an AI-powered personal finance and FinTech dashboard built with Python and Streamlit.



\## Features



\- Interactive financial dashboard

\- Expense and income tracking

\- Financial data visualization

\- AI-powered financial insights

\- Streamlit interface



\## Tech Stack



\- Python

\- Streamlit

\- Pandas

\- Plotly



\## Run Locally



```bash

pip install -r requirements.txt

streamlit run app.py
